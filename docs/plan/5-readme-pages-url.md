## 목적
README만 보고도 배포된 앱에 들어갈 수 있게 GitHub Pages 주소와 배포 방식을 적는다. #1이 끝났는데 로드맵에 "예정"으로 남은 상태도 같이 바로잡는다.

## 규칙 / 변경 내용
- [확정] `README.md` "배포" 절을 아래 내용으로 바꾼다.
  - 주소: https://syc030403.github.io/maple-roster/
  - `main`에 반영되면 GitHub Actions가 검증(lint·typecheck·test·build) 후 자동 배포한다는 설명 한 줄. `develop`은 배포되지 않는다.
- [확정] `docs/design/00-overview.md` 로드맵 표 1번 상태: "예정" → "완료 (#1)". 앞으로 끝난 행도 "완료 (#N)" 형식으로 적는다.
- [확정] 이 브랜치에서 따로 PR을 낸다(다음 기능 작업과 묶지 않음).
- [추론] 주소에 들어가는 GitHub 계정 이름은 저장소 URL로 이미 공개된 값이라 공개 파일에 적어도 된다.
