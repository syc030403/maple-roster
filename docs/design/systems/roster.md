# area:roster — 내 캐릭터와 전체 직업

## 규칙
- [확정] 내 캐릭터: `character/list` 결과를 월드별로 묶어 레벨 내림차순, 같은 레벨은 이름순 (`src/logic/groupCharacters.ts`, #7). 항목은 이름·직업·레벨.
- [임시] 월드 순서: 그 월드의 최고 레벨 내림차순, 같으면 월드 이름순.
- [확정] 전체 직업: `src/data/jobs.json` 기준. 내 캐릭터 직업과 대조해 "보유 / 미보유" 필터 제공.
- [확정] 월드 선택 (#3에서 구현): 사용자가 월드를 지정하면 그 월드의 캐릭터만으로 목록과 직업 보유 여부를 계산한다. "전체 월드" 선택도 둔다. 마지막 선택은 `localStorage`에 기억한다.
- [임시] 같은 직업이 여러 개면 가장 레벨이 높은 캐릭터를 대표로 보여준다.
- [확정] 직업 보유 계산은 `src/logic/`의 순수 함수 + 테스트.
