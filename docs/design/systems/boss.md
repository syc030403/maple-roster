# area:boss — 전투력, 보스 추천, 처치 현황

## 규칙
- [확정] 캐릭터 선택 시 `character/stat`의 "전투력"을 보여준다.
- [확정] 추천 보스는 12마리 (주간 보스 결정석 판매 한도).
- [확정] 권장 전투력 기준은 직접 정리한 `src/data/bosses.json`이 우선. 공식·외부 수치가 있으면 참고로 반영하고 `source`에 적는다.
- [임시] 추천 규칙: `src/data/bosses.json`의 권장 전투력 이하인(잡을 수 있는) 보스·난이도 중 결정석 가격이 높은 순으로 12개. 같은 보스는 난이도 하나만.
- [확정] 주간 보스뿐 아니라 월간 보스(검은 마법사 등)도 전투력 조건만 맞으면 추천 후보에 넣는다.
- [확정] 추천 목록에서 이번 주에 처치한 보스는 "처치"로 표시한다.
- [확정] 처치 현황은 사용자가 직접 체크하고 `localStorage`(`src/storage/`)에 캐릭터별로 저장한다.
- [확정] 주간 초기화: 매주 목요일 00:00 (KST).
- [확정] 추천·초기화 계산은 `src/logic/`의 순수 함수 + 테스트 (경계: 전투력이 기준과 같을 때, 후보가 12개 미만일 때, 목요일 00:00 직전·직후).
